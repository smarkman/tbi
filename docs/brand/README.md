# TBI brand (captured from the live tbiport.org theme)

Logo: `tbi-logo.png` (372×160 PNG from ShulCloud; ask the designer for the original SVG or a high-res version).

## Fonts
- Headings: **Raleway** 600–700 (theme H2 42px/700, H3 24px/600, navy)
- Body: **Open Sans** 400, 18px

## Colors
| Role | Hex |
|---|---|
| Navy (headings, footer, top bar) | `#002E3F` |
| Link / primary button | `#00648B` |
| Logo blue (wordmark) | `#0595D3` |
| Brand green (buttons, logo) | `#A2CD4E` |
| Page background (cream) | `#FCFBF8` |
| Light blue tint | `#E6F4FB` |
| Light green tint | `#F1F9EC` |
| Body text grey | `#525252` |

Accessibility note: the live site puts white text on the green `#A2CD4E` buttons (contrast about 1.8:1, which fails WCAG). The mockup uses navy text on green instead (about 8.6:1).
The site also loads a ShulCloud CSS override file, so custom CSS is available for this theme.
